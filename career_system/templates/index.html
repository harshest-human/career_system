Google Drive 1-Click Sync Setup Guide

Follow these 4 quick steps to create a private Google Drive folder upload webhook:

  1. Go to script.google.com and click New Project.
  2. Copy and paste the Apps Script template below, replacing all text in Code.gs.
  3. Click Deploy → New Deployment → Select type: Web App.
    • Execute as: Me
    • Who has access: Anyone (needed so local requests can post files).
  4. Copy your Web App URL (ends in /exec) and paste it into Step 1.
