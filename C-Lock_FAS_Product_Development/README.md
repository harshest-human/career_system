# C-Lock application - LaTeX

One-page European-style CV and one-page strategic cover letter for a proposed dual role:

- Field Application Scientist, DACH and Northern Europe
- Product Development Manager, affordable barn monitoring

Build both documents with the bundled or system Python runtime:

```powershell
python build.py
```

The final PDFs are written to `build/`.

Personal details are centralized in `data.tex`. The visual system is defined in `style.tex` using Trebuchet MS headings, Segoe UI body text, field green (`#174A3A`), sensor lime (`#A8C64A`) and slate (`#334155`).
